## 須保留的職責與高風險差異

| 主題 | Skill 邊界 | 不可直接消除的條款 |
|---|---|---|
| 設計諮詢 | design-consultation vs layout/editorial | 真正不同的結構方案、一次一個決策問題；正式交付要求完整 13 欄 Design Brief；受測模型禁止偷看 scenario-tests |
| 結構與構圖 | layout-craft vs editorial-layout-design | Layout ≠ Theme；prototype ≠ 獨立成品；四尺寸目視 QA、375 邊界案例按對象保留 |
| 功能 vs 段落 | ui-craft vs section-pattern-craft | Block Registry 查重、Section Pattern 可選、插槽真實目標與既有元件重用 |
| 動效 | motion-craft | subtle 預設、觸控降級、prefers-reduced-motion、不能用動畫彌補薄弱 Layout、無 JS 必須可讀 |
| 實際內容 | content-publishing vs content-readiness | 未公開草稿不得外洩；Pagefind 是 build 索引；示範內容不可冒充真實資料；內容缺口不必阻擋技術 Build |
