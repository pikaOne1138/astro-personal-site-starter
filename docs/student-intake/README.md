# 建站前 AI 訪談包｜學員使用說明

你不需要先想好所有答案，也不需要學會程式。**先把這個資料夾的四份文件一起提供給 AI**（上傳至對話、ChatGPT Project 或支援附檔的編程環境），然後告訴 AI：「請開始建站前訪談」。

## 四份文件
1. **01-AI-訪談主持人.md**：AI 的訪談規則。請 AI 先讀它，依序一次問一個問題，陪你討論，不要直接寫網站。
2. **02-網站定位與個人介紹.md**：網站目的、讀者、風格、About 草稿；不知道的欄位可以空白。
3. **03-內容準備-二選一.md**：知識型準備文章或主題清單；助人者準備服務、流程、FAQ。只填自己那一半。
4. **04-圖片與發布準備.md**：Logo、照片授權、網站連結與是否可以公開。

## 開場語（複製到 AI）
> 我完全沒有網站開發背景。我已上傳「建站前 AI 訪談包」。請先讀 01-AI-訪談主持人.md，再參考其他文件目前填寫的內容。請像一位會引導對話的網站企劃，**一次只問我一個最有幫助的問題**，允許我回答「不知道」。先幫我釐清定位與準備真實內容，不要立刻做網站、要求註冊帳號或寫程式。最後幫我產出一份可讓我確認的《網站內容準備稿》，再帶我到 /starter/ 規劃器。

## 真正完成的標準
- 網站類型明確（知識／部落格，或助人者／個人專業服務）
- 有網站名稱暫定版、清楚的主要讀者、主要行動與一句話介紹
- 有可用的 About 第一版
- 知識型至少有一篇可公開文章的草稿，或清楚標記尚缺文章；助人者有服務說明、合作流程、FAQ 與真實聯絡方式（可以暫不公開）
- 知道哪些照片與圖像可合法使用，哪些是待準備，不虛構 Logo/證照/見證
- AI 整理出 **已確認／草稿待確認／缺少資料／不公開** 四種狀態
- 在學員本人確認內容之前，不把草稿視為已同意發布

## 下一步
這個訪談包是內容準備，不會直接產生網站。整理完成後，前往工作坊的 `/starter/` 選 Layout、配色、頁面、導航、Section Patterns，匯出 Site Brief JSON，再進入 AI 組站流程。**首頁 Layout 原型不等於已完成的多頁網站**。
