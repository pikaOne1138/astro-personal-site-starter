# 改設計，有三種程度｜學員說明卡

這張卡說明你想改網站的樣子時，AI 會怎麼處理。/guide/ 頁面顯示的就是下面編號的三點，兩邊內容來自這一份；`AGENTS.md` 用同樣的三句話。

1. **換配色、字體、站名或 Logo**：可以直接跟 AI 說，例如「把網站改成森林綠」。整個網站會一起換，不用你一頁一頁指定；AI 會直接動手，改完給你看預覽。
2. **換版型或換設計款式**：這會改變網站的排版與氣氛，不只是換顏色。AI 會先做一個預覽給你看，你說「可以」才算數；不滿意可以退回。
3. **改某一個地方的樣子**，例如「只有首頁的按鈕大一點」「卡片的陰影淡一點」：AI 會先說明它打算動哪些地方、哪些頁面會受影響，改完固定回報改了哪裡、影響哪些頁面、有沒有還沒處理好的地方，以及檢查結果（沒檢查的會寫「未測試」）。只想改一處時，AI 不會為了它去動整個網站的設定。

提醒：換配色只換顏色與設計數值，字級、留白、版面編排屬於版型，要換版型才會變。
