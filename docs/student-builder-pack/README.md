# 學員操作說明：AI 建站指引包

這份 ZIP 是給 AI 閱讀的簡短指引，不要求學員研究程式或 Skill 清單。

1. 在 /starter/ 規劃自己的網站並下載 Site Brief JSON。
2. 在 AI 網頁的同一段對話中上傳 Site Brief JSON 與此 ZIP。
3. 貼上：「我已上傳規劃檔與 AI 建站指引包，請幫我建立獨立網站。先確認你能讀寫我的 GitHub Repo、開 PR 與進行雲端建置。所有操作由你處理，我只在網頁確認。不要自行合併或發布。」

如果 AI 網頁不能讀取 ZIP，先解壓縮後上傳內部 Markdown 文件。

**重要**：本包不是整份 Starter 原始碼或完整 Skill 離線封存。AI 需透過 GitHub 查閱最新專案原始碼與技能文件；僅有聊天能力的 AI 不能保證完成建站。學員不必先將 JSON 放入 GitHub。
