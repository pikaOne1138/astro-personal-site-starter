# Layout 示範媒體的授權與替代（給建站 AI）

ZIP 的 Layout 原型可能包含來自外部 Manus 範例的遠端圖片、音訊 URL。**原型展示不等於學員取得重製／再散布授權**；遠端 URL 的可用性也不保證。不得直接把原始圖片 URL 用於正式學員站。

1. 讀取學員選的 Layout，把所有 `img src`、`picture srcset`、`audio src`、CSS `url(...)` 逐一列成待替換資產清單。
2. 只有學員提供且確認授權的圖片／音訊才移進學員站 `public/`。不要代替學員虛構個人照片、證照、客戶作品或營業場所。
3. 若未取得媒體，保留 Layout 的比例、figure、留白與響應式裁切行為，使用清楚標為 Demo 的 CSS/SVG 幾何占位素材；不要讓破圖 icon、空音訊播放器假裝可用。
4. 對影像檢查 naturalWidth，對 audio 檢查可以播放與是否有可用的 transcript/文字替代。無資源時播放器應顯示「示意音訊，尚未提供」，而不是可以點卻無聲音。
5. 部署前把示意資產、外部 URL、圖片授權狀態逐一列出；未經確認的素材不宣稱已可商用。

驗收：兩類學員生成站要在至少 390 與 1440px 下保有 Layout 的圖片區塊比例；再完成其他指定視口測試。
