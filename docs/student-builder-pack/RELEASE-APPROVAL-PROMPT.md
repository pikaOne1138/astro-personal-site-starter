# 學員正式發布指令（唯一來源）

使用前提：只可在學生已看過對應 SHA 的真實 PR Preview、完成內容與手機驗收後，由學生本人複製送出。勾選網頁清單不構成發布同意。

我已檢查這次網站修改，請先向我回報要合併的 PR、目前 Head SHA、與這個 SHA 對應的真實 Preview URL、預計更新的正式網站，以及是否可能修改公開內容。若與我看過的版本不一致，或缺乏真實預覽／必要檢查，請停止並說明。

我在本訊息中明確授權：僅在版本一致、必要檢查通過，而且我已確認該版本時，合併這個 PR 並依既有正式部署流程發布。不要修改其他 PR、DNS、部署平台、帳號權限或與本次無關的設定。如發布還需要其他高風險動作，必須另行取得我的明確核准。

正式發布後，請以真實 URL／部署紀錄核對：首頁、主要內頁、桌機與手機導覽、圖片、聯絡 CTA、預約或表單是否接到真正服務、404、Pagefind（若有）、robots、canonical、sitemap。Preview 應避免索引，Production 應遵照學生的公開索引決定；不得聲稱搜尋引擎已經收錄。

請交付正式網址、部署 SHA、成功與失敗項目、PR 與 Actions 連結、日後更新及還原方式。不能驗證的項目標示「未驗證」，不能假裝成功。
