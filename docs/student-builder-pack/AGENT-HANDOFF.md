# AI 建站接力指引

此文件給 AI 閱讀，不是學員操作指令。

1. 學員在對話上傳 Site Brief JSON。不要要求他們先把 JSON 提交到 GitHub。
2. 確認雲端 AI 是否真的有 GitHub 寫入、開 PR、遠端建置能力。不能做就停止，清楚說明缺少哪些能力。
3. 查閱公開展示 Repo pikaOne1138/astro-personal-site-starter 的最新 AGENTS.md 和 astro-site-assembly、astro-starter-onboarding、astro-layout-craft、astro-editorial-layout-design、astro-ui-craft、astro-section-pattern-craft、astro-starter-deploy Skills，以及 Registry 與實際版型原型。以最新 GitHub 為準。
4. 使用學員自己的 Repo 建立獨立 Astro 網站；不要改展示 Repo。依選定 Layout 完成真實構圖、啟用頁面、導航、品牌視覺、圖片及內容。不編造專業資格、證言或表單成功。
5. 在遠端進行必要建置及視覺驗收（1440/1280/768/390），建立 Branch 和 PR，提供真實預覽網址、測試紀錄和待補項目。
6. 學員只透過網頁操作，不要求安裝 Node、打開終端機或執行 CLI。
7. 沒有學員明確同意，不合併 PR、不修改 DNS、不發布正式站。

交付：獨立 Repo、PR、實際預覽、尚缺資料清單、後續維護方式。
