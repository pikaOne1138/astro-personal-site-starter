    預約初談

    COACHING · PERSONAL GROWTH · Quiet Studio

    以目標與行動為中心的教練服務

    教練式對話聚焦目標、選擇與行動。不是替你做決定，而是透過提問與回顧，讓你更清楚自己想往哪裡走。

    這項服務適合誰？

    可能適合你

    • 有目標但想釐清優先順序與下一步的人
    • 願意在對話之間嘗試行動並回顧的人

    可能需要其他資源

    • 需要心理疾病診斷、治療或危機處理者
    • 期待教練代替自己做選擇或保證達成特定成果者

    教練不取代心理諮商、醫療或法律與財務專業服務。
