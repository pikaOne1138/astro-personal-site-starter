02

品牌視覺

先選一組配色起點，再自由調整五色盤。這些是配色預設，不會改變你在步驟 01 選的整頁 Layout。

優先使用上方選擇檔案：照片會留在瀏覽器內，不會上傳伺服器；下載的 JSON 會包含圖片資料，交給匯出器後才會寫入獨立網站。每張最多 4 MB。若直接填路徑，則需自行放置檔案。未提供時顯示示意圖。

04

選擇組合樣板（選填）

組合樣板不是單顆按鈕，而是完成一件事的整段內容。例如「精選文章／作品」會把標題、說明、代表內容與下一步串起來，幫第一次來的讀者快速找到值得看的東西。

看「精選作品／文章」的整段示範 ↗

適合首頁：先介紹這一區，再放 2–3 篇精選文章、作品或專題，最後提供「查看更多」入口。不是填數字或憑空聲稱成果。

這一段包含：區段前言 → 精選項目列表 → 清楚的下一步
