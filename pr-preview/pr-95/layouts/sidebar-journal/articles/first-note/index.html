把一件小事寫成文章

示範文章：展示窄欄閱讀、側欄索引與正文節奏；內容並非作者的真實經歷。

這是文章正文示範。

有時候，一篇文章只是注意到一件過去沒有察覺的小事。與其急著提出結論，不如先記下當時看見的細節。

留下線索

把觀察放進自己的語言裡，加入日期與主題，往後就能從同一個問題再次出發。

筆記的價值，不一定是答案；也可能是讓問題有地方生長。
