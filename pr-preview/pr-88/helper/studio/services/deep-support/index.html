    SERVICE · Quiet Studio

    深度陪伴

    服務頁不只回答「這是什麼」，還要說清楚適合誰、怎麼進行、費用與下一步。

    適合誰想先把現在的狀況說清楚的人
    形式線上 / 實體
    時間50 分鐘

    你不需要先知道問題的答案

    第一次會談的目的是理解，而不是要求你先整理好自己。這裡會清楚說明工作方式、界線與你可以期待什麼。

    進行方式

    1. 留下簡短需求
    2. 確認時間與形式
    3. 第一次會談
    4. 一起決定是否繼續

    費用與取消

    正式模板應把價格與取消規則放在容易找到的位置，不用逼訪客私訊才知道。
