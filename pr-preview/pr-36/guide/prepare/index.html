前置準備開始建置

PREPARATION / 完全不會程式也能照做

先準備好，再開始建置。

不懂 GitHub、不知道怎麼建立倉庫，甚至還沒有網站名稱、Logo 或文章，都可以從這裡開始。先讓 AI 陪你操作與討論，不必一次把所有問題做完。

GitHub 是什麼？ ↓GitHub 是存放網站原始碼的地方；Repository（倉庫）就是每一個網站專案的資料夾。建立自己的倉庫 ↓第一次先建一個自己的空白倉庫。之後 AI 才知道要把網站放在哪裡。讓 AI 存取倉庫 ↓AI 能聊天，不代表它已經取得 GitHub 存取權。網站內容訪談 ↓沒有 About、文章、服務文案也可以先從 AI 訪談開始。Logo、Favicon 與網站圖片 ↓沒有品牌圖片時，先跟 AI 探索概念，再產出可以替換的示意圖。Cloudflare 事前準備 ↓準備 Cloudflare 帳號；實際部署設定在開始建置頁進行。

01｜認識 GitHub：不用先學會寫程式

GitHub 是保存網站程式與版本的服務。你會用到自己的帳號和一個 Repository（倉庫）。你的倉庫與工作坊展示站是不同的專案，不要讓 AI 直接修改展示站。

  1. 開啟 GitHub 註冊 ↗；若已有帳號，就直接登入。
  2. 登入後，確認右上角頭像選單能看到自己的帳號名稱。
  3. 把帳號名稱記下來；後續你的 Repo 全名會是 帳號名稱/倉庫名稱。
任何畫面找不到按鈕時，不需要亂猜。先截圖給 AI，讓 AI 依你眼前的介面一步一步指引。 截圖前遮住電子郵件、私人 Repo 名稱及敏感資訊；永遠不要傳密碼或 Token。

02｜建立第一個 Repository

  1. 開啟 GitHub New repository ↗。
  2. 確認 Owner 是自己的帳號。
  3. Repository name 輸入英文簡短名稱，例如 my-personal-site。
  4. 選擇 Public 或 Private（Public 原始碼公開；不確定時先問 AI 兩者差異）。
  5. 勾選 Add a README file，其他進階選項可以先保持預設。
  6. 點 Create repository。看到 你的帳號/my-personal-site 的 Code 頁，代表倉庫建立成功。

不會操作時，請把下方提示詞貼給 AI，照它的一個步驟一個步驟做。

我完全不懂 GitHub，請當我的 GitHub 操作教練，陪我從登入到建立自己的網站 Repository。請一次只教我一個步驟，說明要點哪個按鈕、畫面上應該看到什麼，以及完成後如何驗證。如果我的畫面與你說的不一樣，請先叫我截圖上傳，你要根據這張截圖的真實介面重新引導，不要憑空猜位置。必要時在每個階段幫我整理一段可保存的《GitHub 操作紀錄》，寫下已完成步驟、Repo 名稱、還沒完成的事項。請幫我避開工作坊展示 Repo，不要要求我貼密碼、Token、驗證碼，也不要未經同意改權限或公開私人資料。第一步請只問我是否已登入 GitHub。

03｜讓 AI 真正有權限讀寫你的倉庫

GitHub 帳號建立好，不代表 AI 自動有權限。先在你選用的 AI 工具啟用 GitHub 連接，再開啟 Installed GitHub Apps 管理頁 ↗。

  1. 找到這次使用的 AI App，例如 ChatGPT Codex Connector 或 Claude；按 Configure。
  2. 向下找到 Repository access，建議選 Only select repositories。
  3. 按 Select repositories，把剛剛建立的網站 Repo 加入清單，再按 Save。
  4. 回到 AI 對話，要求它讀取該倉庫的 README.md，並確認是否能對指定 Repo 建 Branch/PR。
若你之後建立了另一個 Repo，可能需要回到這裡重新加入；如果看不到 App，先回到 AI 工具執行 Connect GitHub。不應用公開 Repo 或貼 API Token 來繞過正常授權。

04｜讓 AI 訪談你，寫出網站所需內容

還沒有 About、文章或服務文案都沒關係。教學會提供「建站前 AI 訪談包」，AI 會一次問一個問題，協助整理網站名稱、讀者、主要行動、個人介紹和文章／服務內容。訪談稿不會自動發布。

回到建置頁下載完整訪談包 ZIP ↗

第一句話
我完全不會網站開發。我想請你先擔任我的網站訪談主持人，一次只問我一個問題，協助釐清網站的讀者、名稱、自我介紹、文章或服務內容。我不知道的地方請提供具體例子討論，最後整理出待我確認的網站內容準備稿。請先不要寫程式或公開內容。

05｜不用事先有 Logo：一起做品牌圖像

AI 先從你的網站定位提出三種不同的 Logo 概念，再陪你選擇文字標誌、字母標誌、簡單符號或組合標誌。選定概念後生成 Logo 候選、精簡的 favicon，再製作需要的 Hero、文章封面或服務情境替代圖。

  1. 先選概念，不是只換顏色；黑白版也要清楚。
  2. 中文字形必須人工校對。若 AI 產圖文字錯誤，就先生成純圖形，再用真正字體排版。
  3. favicon 檢查 16、32、48px。不要把整張橫式 Logo 硬縮小。
  4. AI 生成的照片不可以冒充真實執業者、客戶、諮商空間或事件，正式使用還需檢查平台條款及與既有商標的相似性。

訪談 ZIP 內含「AI 品牌識別與圖片共創」與 Logo 設計研究文件。

06｜準備 Cloudflare 帳號

建立或登入 Cloudflare Dashboard ↗。初次製作靜態個人網站，無須先購買網域或開 D1 / R2 / 金流。連接 Repo、設定 Pages 專案、檢查部署，放在「開始建置」的流程中操作。
