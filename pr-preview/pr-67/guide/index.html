Beta 測試版：目前能做什麼、還需要 AI 做什麼？

資料包提供 25 種可產生獨立網站的設計選項，以及網站規劃、文章或服務頁、個人介紹、品牌與導覽設定。AI 可依資料包建立你自己的 Astro 專案，不必複製老師的 Repo。

部分新增設計仍在測試；選擇設計不代表網站已完成驗收。AI 仍需與你確認真實文字、圖片、服務資訊及內頁細節，完成電腦與手機預覽，並由你授權連接 GitHub 與發布平台；下載 ZIP 本身不會直接發布網站。

測試時請記下所選版型、遇到的困難，並把相關畫面截圖回報給工作坊。不要把示範資格、預約、書目、音訊或服務資訊當成真實資料。

如果 AI 無法接收 ZIP，請改用能上傳完整資料夾或多檔專案的工具，解壓後保留 .ai/、src/、scripts/ 等原始目錄結構；不能只傳 README 或幾份 Markdown。若工具無法保留檔案路徑，請先換成支援 ZIP／專案檔案的 AI 工作模式，再開始建站。
