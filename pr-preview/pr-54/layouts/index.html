HOW TO CHOOSE

先選閱讀動線，
再決定顏色。

01．你希望訪客先做什麼？ 閱讀觀點、探索文章、跟著學習、收聽節目，還是確認專業服務。

02．你最主要的內容是什麼？ 長文、分類資料庫、課程、影像、影音、服務流程，會決定適合哪種首頁排列。

03．最後才調整品牌視覺。 色彩、字體、圓角、動效，都可以在選定版面結構後再更改。
